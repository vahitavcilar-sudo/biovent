# Biovent V5 — indirilebilir yerel test

Windows bilgisayarda gerçek siteyi açmak için **biovent-v5-windows-test.zip** dosyasını indirin. GitHub dosya sayfasındaki Download raw file düğmesini kullanın.

1. ZIP dosyasına sağ tıklayın → Tümünü ayıkla.
2. biovent-v5-test klasöründe SITEYI-AC.bat dosyasına çift tıklayın.
3. Tarayıcı otomatik açılır; siyah pencereyi açık tutun.

Node.js veya Python kurmanız gerekmez. Dört dil, 44 sayfa, orijinal logo ve Smart fotoğrafı, V5 hareketleri, teknik seçimler, kataloglar ve distribütör formu yerel olarak çalışır. 440 ekran kontrolü, 47 erişilebilirlik taraması ve hareket testleri geçti. Windows başlatıcısı çapraz derlendi; aynı sunucu Linux üzerinde test edildi, Windows EXE bu ortamda çalıştırılmadı. Form test modunda: e-posta göndermez. Canlı Natro/JetPress sitesi değiştirilmedi. Gerçek firma/hukuki bilgiler ve mail servisi yayından önce doğrulanmalıdır.

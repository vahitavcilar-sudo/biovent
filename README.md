# Biovent V4 kaynak teslimi — TASLAK

İndirmek için bu daldaki `biovent-v4-source.zip` dosyasını açın ve **Download raw file** düğmesine basın.

ZIP dosyasını bilgisayarınızda çıkarın. İçindeki `biovent-v4/ONIZLEME.html` dosyasına çift tıklayarak tasarımın ekran görüntülerini görün. Bu HTML, etkileşimli uygulama değil; bağımsız bir ekran görüntüsü önizlemesidir.

Etkileşimli siteyi bilgisayarınızda çalıştırmak için Node.js 20.9+ gerekir. ZIP içindeki `biovent-v4` klasöründe terminal açın:

```sh
npm ci
npm run dev
```

Terminalin yazdığı yerel adresi tarayıcıda açın. Kurulum ve hosting açıklamaları kaynak paketin README.md ve DEPLOY-WORDPRESS-HOSTING.md dosyalarındadır.

Profesyonel Smart fotoğrafının indirilebilir dosyası henüz ulaşmadı; bu nedenle görsel alanları geçicidir. Paket tamamlanmış üretim sürümü değildir. Mevcut WordPress sitesi değiştirilmedi veya yayınlanmadı.

ZIP bütünlüğü SHA256SUMS.txt ile kontrol edilebilir.

# Biovent V4 — bilgisayarınızda çalışan site testi

## Windows test paketini indirin

[**biovent-v4-windows-test.zip — yaklaşık 41 MB**](https://github.com/vahitavcilar-sudo/biovent/raw/refs/heads/delivery/v4-2026-10-09/biovent-v4-windows-test.zip)

1. ZIP dosyasına sağ tıklayıp **Tümünü ayıkla** seçin.
2. Çıkarılan **biovent-v4-test** klasörünü açın.
3. **SITEYI-AC.bat** dosyasına çift tıklayın.
4. Tarayıcınız otomatik açılır; Türkçe ana sayfadan gerçek siteyi gezebilirsiniz.
5. Siyah pencereyi test boyunca açık tutun; bitirdiğinizde kapatın.

Node.js, Python, npm veya hosting kurulumu gerekmez. Windows 10/11 64 bit içindir. ZIP içinden çalıştırmayın; önce bütün dosyaları çıkarın. Tarayıcı otomatik açılmazsa konsoldaki adresi tarayıcınıza kopyalayın.

Bu paket ekran görüntüsü önizlemesi değildir: gerçek HTML/CSS/JavaScript, dört dilde 44 sayfa, ürün seçimleri, mobil menü ve PDF'ler çalışır. İnternet yalnızca ZIP'i indirmek için gerekir; yerel site dosyaları pakettedir. Başlatıcı sadece bilgisayarınızın 127.0.0.1 adresinde dinler ve kalıcı kurulum yapmaz.

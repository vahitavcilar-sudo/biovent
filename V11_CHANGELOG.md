# BioVent V11 change log

## Product and professional experience

- Retained the four-product Smart-first hero, distinctive product choreography, continuous Smart engineering journey, official logo, genuine renders and four languages.
- Added a reusable technical dossier for each implant family: authentic image zoom/reset, keyboard and mouse inspection, documented feature selection, Smart hotspots, source-PDF links and family-scoped prosthetic documentation.
- Added 84 catalogue-listed diameter/length configurations, shared by product summaries, selectors, comparison and professional enquiries. Smart now uses Ø5.5 instead of the incorrect Ø5.0. Invalid pairs and the unresolved Ø5.5×15 option are excluded; ambiguous Monoblock Ø3.3 implant codes remain unpublished.
- Added a separate professional information / quotation route in EN/DE/TR/AR, with validated product prefill, exact reference derivation, optional quantity/phone, consent, separate session draft, error focus, honest preview download and an explicitly configured receiving-service contract. Distributor applications remain separate.
- Improved two/three-system focused comparison while preserving the four-system overview. Added real catalogue search, product/category filters, English file-language labels and clear reset/empty states.

## Presentation and engineering

- Refined manufacturer introduction, linked four-system assembly, catalogue-based technical pathways, source-documentation section and separate professional/distributor conversion finale.
- Updated header/footer product-information paths, product-section navigation, localized technical text and the sitemap to 48 localized routes.
- Improved image viewer and form accessibility, footer contrast and unobscured product-link targets. Direct page openings keep SSR content visible immediately.
- Made `npm run export` portable to Windows and POSIX without adding a dependency. Preserved static Apache/LiteSpeed packaging, root/base-path configuration, SEO/hreflang and reduced-motion behavior.
- No new runtime dependency, invented CAD, fake clinical geometry, stock factory image, certification, manufacturing-origin statement or clinical outcome claim was introduced.

## Replaced behavior and limits

Product detail enquiry links now open the professional workflow instead of the distributor application; the latter remains available through a separate explicit path. V10's valid functionality was extended, not removed.

No live form receiver, verified legal/controller details or Natro deployment was supplied. Forms remain preview-only by default. New Promx original PNG, approved CAD/extra angles, certain per-variant prosthetic/clinical documents and manufacturing/certification evidence remain missing. See the product audit, required-assets and QA reports. No live website changes were made.

## Playback correction — 20 October 2026

Explicit play now starts automatic progression under the pointer and on the focused play button; new user interactions still pause safely. A four-language status explains pause/device/data constraints, including on mobile. See `V11_MOTION_FIX.md` for this build’s targeted validation and updated Windows package. Old QA movies are excluded from that local-review package.

## Five-second slider — 20 October 2026

Automatic progression is now 5000 ms. Hover, keyboard focus and manual selections no longer pause it; each manual selection resets the full interval. Explicit pause/resume remains available. Reduced motion and data saving use instant changes on the same interval. See `V11_SLIDER_5S.md`.
